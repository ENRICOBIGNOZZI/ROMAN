# Data

No third-party dataset is bundled.

For the StockX research replay, obtain the public 2019 StockX Data Contest CSV from its original/publicly authorized source and run:

```bash
python scripts/run_stockx_replay.py data/StockX-Data-Contest-2019-3.csv
```

For real live research, add authorized API/feed adapters rather than bypassing marketplace access controls or terms.
